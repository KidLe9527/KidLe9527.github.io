# 微机原理速成笔记！



1. **大端存储**：高位字节在前（低地址）、低位字节在后（高地址），符合人类读写习惯，核心是 “高高低低”。
2. **小端存储**：低位字节在前（低地址）、高位字节在后（高地址），是现代处理器的主流方式，核心是 “低高低高”。
   * 字节位次指的是排列顺序，高位字节是指在数据中在高位的数据；地址顺序是从低到高，高地址指的是在内存中排在后面的地址

> ### 具体例子（以 32 位整数 `0x12345678` 为例）
>
> 假设我们有一个 32 位（4 字节）的十六进制数 `0x12345678`，拆解成 4 个字节：
>
> - 最高位字节：`0x12`
> - 次高位字节：`0x34`
> - 次低位字节：`0x56`
> - 最低位字节：`0x78`
>
> 我们把这个数存入内存地址从 `0x00` 到 `0x03` 的连续空间中，两种存储方式的对比如下：
>
> | 内存地址 | 大端存储（字节值） | 小端存储（字节值） |
> | -------- | ------------------ | ------------------ |
> | 0x00     | 0x12（高位）       | 0x78（低位）       |
> | 0x01     | 0x34               | 0x56               |
> | 0x02     | 0x56               | 0x34               |
> | 0x03     | 0x78（低位）       | 0x12（高位）       |







场景 4：从奇地址读一个字（非对准字，图 d） 非对准字～

- 地址：`A0001H`（奇地址，A₀=1）
- 操作：
  1. **第一次总线周期**：激活奇地址存储体，读取`X`（通过高 8 位总线），偶地址存储体的`Y`被忽略。
  2. **第二次总线周期**：地址 + 1 变为`A0002H`（偶地址），激活偶地址存储体，读取`W`（通过低 8 位总线），奇地址存储体的`Z`被忽略。
  3. CPU 将两次读取的结果组合成字`WX`。
- 特点：这种从奇地址开始的字叫**非对准字**，需要两次总线周期，效率较低。







1. 可用寄存器列表

能用于间接寻址的寄存器只有 4 个：

`BX`（基址寄存器）、`BP`（基址指针寄存器）、`SI`（源变址寄存器）、`DI`（目的变址寄存器）。

> 它们被称为 “专用寄存器”，是 8086 架构里专门设计用来存放内存地址偏移量的。

------

2. 段寄存器的默认配对规则

这是最关键的一点，不同的间接寻址寄存器，会默认和不同的段寄存器组合生成 20 位物理地址：

| 间接寻址寄存器   | 默认配对的段寄存器 | 物理地址计算方式                            |
| ---------------- | ------------------ | ------------------------------------------- |
| `BX`、`SI`、`DI` | 数据段 `DS`        | `物理地址 = (DS) × 16 + 寄存器中的偏移地址` |
| `BP`             | 堆栈段 `SS`        | `物理地址 = (SS) × 16 + (BP)`               |

------

3. 为什么要这样配对？

- `BX`、`SI`、`DI` 通常用来访问**数据段**里的变量和数组，所以默认和 `DS` 绑定。
- `BP` 专门用来访问**堆栈段**里的栈帧数据（比如函数的局部变量、参数），所以默认和 `SS` 绑定。也可以是sp（堆栈指针）

> 例如：
>
> `MOV AX, [BX]` → 从 `DS:BX` 指向的内存地址读取一个字到 `AX`。
>
> - `MOV AX, [BP]` → 从 `SS:BP` 指向的内存地址读取一个字到 `AX`。





🔥！！ I/O 端口寻址 

> 1. **数据寄存器**：I/O 操作的数据只能通过 `AL`（8 位）或 `AX`（16 位）传输。
> 2. **地址寄存器**：端口地址如果是 16 位，必须放在 `DX` 寄存器中；如果是 8 位，可以直接写在指令里。





`PUSH AX`

- **目的操作数**：隐含为 `SS:SP-2` → **寄存器间接寻址**（堆栈段 `SS`）
- **源操作数**：`AX` → **寄存器寻址**
- **作用**：将 `AX` 内容压入堆栈：`SP` 减 2，然后将 `AX` 存入 `SS:SP` 指向的栈顶。







8086 指令集分类详解

> 8086 指令集按功能可分为以下六大类，下面为你逐一介绍核心指令及用途：
>
> ------
>
> ## 一、数据传送指令
>
> 这是最基础、最常用的指令类型，负责在寄存器、内存和 I/O 端口之间传递数据。
>
> - **MOV**：核心通用传送指令，格式为 `MOV 目标, 源`，可实现寄存器之间、寄存器与内存之间的数据传递，但不能直接在两个内存单元间传送。
> - **PUSH/POP**：堆栈操作指令，`PUSH` 将数据压入栈顶，`POP` 从栈顶弹出数据到目标位置，常用于函数调用时保存和恢复现场。
> - **XCHG**：交换指令，交换两个操作数的内容，支持寄存器之间、寄存器与内存单元之间的数据交换。
> - **IN/OUT**：I/O 端口传送指令，`IN` 从 I/O 端口读取数据到累加器，`OUT` 将累加器的数据输出到 I/O 端口。
> - **LEA**：有效地址传送指令，将内存单元的偏移地址（而非内容）加载到寄存器中，例如 `LEA BX, [SI+100H]`。
>
> ------
>
> ## 二、算术运算指令
>
> 用于执行二进制的加减乘除及相关辅助运算，运算结果会影响标志寄存器（如 CF、ZF、SF、OF 等）。
>
> - **ADD/ADC**：加法指令，`ADD` 是普通加法，`ADC` 是带进位加法，多用于多字节 / 多字数据的高位相加。
> - **SUB/SBB**：减法指令，`SUB` 是普通减法，`SBB` 是带借位减法，与 `ADC` 对应，用于多字节 / 多字数据的高位相减。
> - **INC/DEC**：自增 / 自减指令，对操作数加 1 或减 1，常用于循环计数。
> - **MUL/IMUL**：乘法指令，`MUL` 是无符号数乘法，`IMUL` 是有符号数乘法，8 位乘法结果存于 `AX`，16 位乘法结果存于 `DX:AX`。
> - **DIV/IDIV**：除法指令，`DIV` 是无符号数除法，`IDIV` 是有符号数除法，16 位被除数存于 `AX`，32 位被除数存于 `DX:AX`。
> - **NEG**：求补指令，对操作数取补码（即相反数），相当于用 0 减去该操作数。
>
> ------
>
> ## 三、逻辑运算与移位指令
>
> 主要用于对二进制位进行操作，包括逻辑运算、移位和循环移位。
>
> - **AND/OR/XOR/NOT**：逻辑运算指令
>   - `AND`：按位与，可用于清除某些位（如 `AND AL, 0FH` 保留低四位，清零高四位）。
>   - `OR`：按位或，可用于设置某些位（如 `OR AL, 80H` 置最高位为 1）。
>   - `XOR`：按位异或，可用于翻转某些位或清零自身（如 `XOR AX, AX` 快速将 AX 清零）。
>   - `NOT`：按位取反，单操作数指令。
> - **SHL/SHR**：移位指令
>   - `SHL`：逻辑左移，每左移一位，最高位进入 CF，最低位补 0，相当于无符号数乘以 2。
>   - `SHR`：逻辑右移，每右移一位，最低位进入 CF，最高位补 0，相当于无符号数除以 2。
> - **SAL/SAR**：算术移位指令
>   - `SAL`：算术左移，与 `SHL` 功能完全相同。
>   - `SAR`：算术右移，每右移一位，最低位进入 CF，最高位保持原符号位不变，用于有符号数除以 2。
> - **ROL/ROR/RCL/RCR**：循环移位指令，可实现位的循环移动，其中 `RCL` 和 `RCR` 会结合进位标志 CF 一起参与循环。
>
> ------
>
> ## 四、程序控制指令
>
> 用于改变程序的执行流程，实现分支、循环和跳转。
>
> - **JMP**：无条件跳转指令，直接跳转到目标地址执行，支持短跳转、近跳转和远跳转。
> - **条件跳转指令**：根据标志寄存器的状态决定是否跳转，例如 `JE/JZ`（等于 / 为零则跳转）、`JNE/JNZ`（不等于 / 不为零则跳转）、`JC`（有进位则跳转）、`JS`（结果为负则跳转）等，这类指令通常紧跟在算术 / 逻辑运算指令之后。
> - **CALL/RET**：子程序调用与返回指令，`CALL` 调用子程序时会将当前指令地址压栈，然后跳转到子程序入口；`RET` 从子程序返回时，将栈中保存的地址弹出到 IP（远返回时还会弹出 CS），恢复原程序执行。
> - **INT/IRET**：中断调用与返回指令，`INT n` 触发类型为 `n` 的软中断，`IRET` 从中断服务程序返回，会恢复标志寄存器、CS 和 IP 的值。
>
> ------
>
> ## 五、串操作指令
>
> 专门用于对内存中的数据串（字节串或字串）进行批量操作，配合重复前缀可实现高效的串处理。
>
> - **MOVS**：串传送指令，将 `DS:SI` 指向的源串数据传送到 `ES:DI` 指向的目标串，自动修改 SI 和 DI 的值（方向由 DF 标志决定，DF=0 时递增，DF=1 时递减）。
> - **CMPS**：串比较指令，比较 `DS:SI` 和 `ES:DI` 指向的串元素，结果影响标志寄存器。
> - **SCAS**：串扫描指令，用累加器（AL/AX）的值扫描 `ES:DI` 指向的串，查找匹配或不匹配的元素。
> - **LODS/STOS**：串加载 / 存储指令，`LODS` 将 `DS:SI` 指向的串元素加载到累加器，`STOS` 将累加器的值存储到 `ES:DI` 指向的目标串。
> - **重复前缀**：`REP`、`REPE/REPZ`、`REPNE/REPNZ`，可加在串操作指令前，实现指令的重复执行，直到满足结束条件（如 CX 减到 0，或标志位不满足）。
>
> ------
>
> ## 六、处理器控制指令
>
> 用于控制处理器的状态、标志位，或实现空操作等辅助功能。
>
> - **CLC/STC/CMC**：进位标志控制指令，分别用于清零 CF、置 1 CF、翻转 CF。
> - **CLD/STD**：方向标志控制指令，`CLD` 使 DF=0（串操作时 SI/DI 递增），`STD` 使 DF=1（串操作时 SI/DI 递减）。
> - **CLI/STI**：中断标志控制指令，`CLI` 关闭可屏蔽中断（IF=0），`STI` 开启可屏蔽中断（IF=1）。
> - **NOP**：空操作指令，占用 1 字节，执行时不改变寄存器和内存，仅消耗一个指令周期，常用于延时或指令对齐。
> - **HLT**：停机指令，使处理器进入暂停状态，直到有中断或复位信号才会恢复执行。







```8086
; 8086汇编实现符号函数（Sign Function）
; 功能说明：
; - 当 X > 0 时，Y = 1
; - 当 X = 0 时，Y = 0
; - 当 X < 0 时，Y = -1（8位有符号数用 0FFH 表示）
; 编译环境：MASM/TASM 8086汇编器

; 数据段定义：存放变量
DATA SEGMENT
    X DB -25     ; 定义字节变量X，赋值为-25（8位有符号数，补码形式为0E7H）
    Y DB ?       ; 定义字节变量Y，仅分配1字节存储空间，初始值未指定
DATA ENDS        ; 数据段结束

; 代码段定义：存放执行逻辑
CODE SEGMENT
    ; 告诉汇编器段寄存器与段的对应关系
    ASSUME CS:CODE, DS:DATA  

; 程序入口点
START:
    ; 初始化数据段寄存器DS（8086不能直接给段寄存器赋值，需通过通用寄存器中转）
    MOV AX, DATA  ; 将数据段的段地址加载到AX寄存器
    MOV DS, AX    ; 将AX的值送入DS，完成DS初始化，使程序能访问DATA段的变量

    ; 核心逻辑：判断X的符号并给Y赋值
    MOV AL, X     ; 将变量X的值加载到8位寄存器AL中
    CMP AL, 0     ; 比较AL（即X）与0，仅影响标志寄存器（ZF/SF/OF等），不修改AL
    JGE LOOP1     ; 若AL >= 0（X >= 0），跳转到LOOP1标签处执行
    MOV AL, 0FFH  ; 若X < 0，将AL赋值为0FFH（8位有符号数的-1）
    JMP NEXT      ; 跳过后续判断，直接跳转到NEXT标签保存结果

; 处理X >= 0的分支
LOOP1:
    JE LOOP2      ; 若AL == 0（X == 0），跳转到LOOP2标签处执行
    MOV AL, 1     ; 若X > 0，将AL赋值为1
    JMP NEXT      ; 跳转到NEXT标签保存结果

; 处理X = 0的分支
LOOP2:
    MOV AL, 0     ; 将AL赋值为0

; 保存结果到变量Y，并退出程序
NEXT:
    MOV Y, AL     ; 将AL中最终的结果（-1/0/1）存入变量Y
    MOV AH, 4CH   ; 设置DOS中断功能号：4CH表示程序正常退出
    INT 21H       ; 调用DOS 21H中断，结束程序并返回操作系统

CODE ENDS        ; 代码段结束
END START        ; 指定程序入口为START标签，汇编器从此处开始生成可执行代码
```





```8086
; 8086汇编程序：统计AX寄存器中二进制位为"1"的个数
; 结果保存在DL寄存器中

CODE SEGMENT
    ASSUME CS:CODE

START:
    MOV CX, 16        ; 初始化循环计数器：AX是16位，需要循环16次
    XOR DL, DL        ; 清零统计计数器DL，用异或比MOV DL,0更高效
    CMP AX, 0         ; 检查AX是否为0，避免无意义的循环
    JZ DONE           ; 如果AX=0，直接跳转到结束

BB1:
    SAL AX, 1         ; 将AX算术左移1位（SHL也可以）
                      ; 左移后，AX的最高位会被移到进位标志CF中
    ADC DL, 0         ; DL = DL + 0 + CF
                      ; 若移出的位是1，CF=1，DL加1；否则CF=0，DL不变
    LOOP BB1          ; CX自动减1，若CX≠0则跳回BB1继续循环
                      ; 循环16次后，CX=0，自动退出循环

DONE:
    MOV AX, 4C00H     ; 设置DOS中断功能号：AH=4CH（正常退出），AL=00H
    INT 21H           ; 调用DOS 21H中断，程序退出并返回操作系统

CODE ENDS
END START
```





```8086
; 功能：控制8个LED同时亮40ms、灭30ms，循环执行
; 端口地址：D_PORT = 0300H

D_PORT EQU 0300H   ; 定义74LS273的端口地址

CODE SEGMENT
    ASSUME CS:CODE

START:
    ; 主循环：亮→延时→灭→延时→重复
MAIN_LOOP:
    ; 点亮所有LED：向端口输出0FFH（全1）
    MOV AL, 0FFH
    OUT D_PORT, AL
    CALL DELAY_40MS  ; 延时40ms

    ; 熄灭所有LED：向端口输出00H（全0）
    MOV AL, 00H
    OUT D_PORT, AL
    CALL DELAY_30MS  ; 延时30ms

    JMP MAIN_LOOP    ; 无限循环

; 延时40ms子程序（基于8086时钟，假设时钟频率为1MHz）
DELAY_40MS:
    PUSH CX
    PUSH DX
    MOV DX, 40       ; 外层循环次数
DLY40_1:
    MOV CX, 1000     ; 内层循环次数
DLY40_2:
    LOOP DLY40_2     ; 内层循环
    DEC DX
    JNZ DLY40_1
    POP DX
    POP CX
    RET

; 延时30ms子程序
DELAY_30MS:
    PUSH CX
    PUSH DX
    MOV DX, 30       ; 外层循环次数
DLY30_1:
    MOV CX, 1000     ; 内层循环次数
DLY30_2:
    LOOP DLY30_2     ; 内层循环
    DEC DX
    JNZ DLY30_1
    POP DX
    POP CX
    RET

CODE ENDS
END START
```





```8086
; 数据段定义
DATA SEGMENT
    TEMP DB 500 DUP (?)  ; 定义500字节的内存空间，存放采集的温度数据
DATA ENDS

; 代码段定义
CODE SEGMENT
    ASSUME CS:CODE,DS:DATA  ; 关联段寄存器与段名
START:
    MOV AX,DATA             ; ①将数据段地址送入AX
    MOV DS,AX               ; ②将AX的值送入DS，完成数据段寄存器初始化
    MOV BX,0                ; ③BX寄存器清0（BH/BL分别用于统计高温/低温次数）
    L0:
    MOV SI,0                ; ④SI作为内存索引，初始化为0（指向TEMP起始地址）
    L1:
    MOV DX,0383H            ; ⑤设置端口地址为0383H（温度采集端口）
    IN AL,DX                ; ⑥从0383H端口读取温度数据到AL（补全①处）
    MOV [SI],AL             ; ⑦将采集的温度数据存入TEMP[SI]内存单元
    INC SI                  ; ⑧索引SI自增，指向下一个内存单元
LP:
    CMP AL,30               ; ⑨比较采集的温度（AL）与30℃
    JG HT                   ; ⑩若温度>30℃，跳转到HT（高温处理）
    JL LT                   ; ⑪若温度<30℃，跳转到LT（低温处理）
    JMP NOM                 ; ⑫若温度=30℃，跳转到NOM（正常处理）
HT:
    INC BH                  ; ⑬高温次数计数器BH自增
    CMP BH,5                ; ⑭比较BH与5（补全②处）
    JB NOM                  ; ⑮若高温次数<5，跳转到NOM
    MOV AL,0EEH             ; ⑯设置高温报警值0EEH到AL
    OUT DX,AL               ; ⑰向0380H端口输出报警值（补全③处，DX仍为0380H？注：原代码中NOM段重新赋值DX=0380H，此处需确认端口，逻辑为输出报警）
LT:
    INC BL                  ; ⑱低温次数计数器BL自增
    CMP BL,3                ; ⑲比较BL与3
    JB NOM                  ; ⑳若低温次数<3，跳转到NOM
    MOV AL,55H              ; ㉑设置低温报警值55H到AL
    JMP ERR                 ; ㉒跳转到ERR执行报警输出
NOM:
    MOV DX,0380H            ; ㉓设置输出端口为0380H
    MOV AL,88H              ; ㉔设置正常输出值88H到AL
    OUT DX,AL               ; ㉕向0380H端口输出88H
    CMP SI,500              ; ㉖比较索引SI与500（判断是否采集完500个数据）
    JZ ERR                  ; ㉗若SI=500，跳转到ERR（补全④处）
    JMP L1                  ; ㉘若未采集完，跳回L1继续采集
ERR:
    MOV DX,0380H            ; ㉙设置输出端口为0380H
    OUT DX,AL               ; ㉚向0380H端口输出最终值（报警/正常）
    MOV AH,4CH              ; ㉛设置DOS中断功能号（程序退出）
    INT 21H                 ; ㉜调用DOS中断，程序结束
CODE ENDS
    END START               ; ㉝程序入口为START，汇编结束
```







# 8086 常用寄存器分工速查表

|    寄存器    |         全称         |            主要用途             |                        典型场景                         |
| :----------: | :------------------: | :-----------------------------: | :-----------------------------------------------------: |
|    **AX**    | Accumulator Register |     累加器，默认运算寄存器      | 算术运算、数据传输、I/O 操作（`IN`/`OUT`指令默认用 AX） |
|    **BX**    |    Base Register     |           基址寄存器            |      存储内存地址的基址部分，常用于`[BX]`间接寻址       |
|    **CX**    |    Count Register    |           计数寄存器            | 循环计数（`LOOP`指令）、串操作重复次数（`REP`/`REPZ`）  |
|    **DX**    |    Data Register     |           数据寄存器            |  扩展 AX 参与双字运算，存储 I/O 端口地址（16 位端口）   |
|    **SI**    |     Source Index     |          源变址寄存器           |           串操作（`MOVS`/`LODS`）的源地址指针           |
|    **DI**    |  Destination Index   |         目的变址寄存器          |          串操作（`MOVS`/`STOS`）的目的地址指针          |
|    **BP**    |     Base Pointer     |            基址指针             |         访问栈帧中的局部变量，默认与 SS 段配合          |
|    **SP**    |    Stack Pointer     |             栈指针              |   始终指向栈顶，管理栈的压入（`PUSH`）和弹出（`POP`）   |
|    **IP**    | Instruction Pointer  |            指令指针             |          指向当前要执行的指令，由 CPU 自动更新          |
|  **FLAGS**   |    Flag Register     |           标志寄存器            | 存储运算结果状态（如零标志 ZF、进位标志 CF）和控制标志  |
| **段寄存器** |     CS/DS/ES/SS      | 代码段 / 数据段 / 附加段 / 栈段 |             配合偏移地址生成 20 位物理地址              |

# 8086 常用指令与寄存器搭配速查表

|   指令类别   |              典型指令              | 必须搭配的寄存器 |                           作用说明                           |
| :----------: | :--------------------------------: | :--------------: | :----------------------------------------------------------: |
| **循环控制** |               `LOOP`               |       `CX`       | `CX`作为循环计数器，每次执行`LOOP`时`CX`自动减 1，直到`CX=0`退出循环 |
|  **串操作**  | `MOVS`/`LODS`/`STOS`/`CMPS`/`SCAS` |  `SI`/`DI`/`CX`  |     `SI`= 源地址指针，`DI`= 目的地址指针，`CX`= 重复次数     |
|              |        `REP`/`REPZ`/`REPNZ`        |       `CX`       |           配合串操作指令，用`CX`控制重复执行的次数           |
| **I/O 操作** |             `IN`/`OUT`             |    `AX`/`DX`     | 8 位端口：`AL`；16 位端口：`AX`；端口号 > 255 时用`DX`存储端口地址 |
|  **栈操作**  |     `PUSH`/`POP`/`CALL`/`RET`      |       `SP`       |           `SP`始终指向栈顶，自动管理栈的压入和弹出           |
| **过程调用** |            `CALL`/`RET`            |    `IP`/`CS`     |    `CALL`保存当前`IP`（或`CS:IP`）到栈，`RET`恢复返回地址    |
| **基址寻址** |           `[BX]`/`[BP]`            |    `BX`/`BP`     | `BX`默认与`DS`段配合，`BP`默认与`SS`段配合，用于间接访问内存 |
| **算术运算** |            `MUL`/`DIV`             |    `AX`/`DX`     | 乘法：16 位结果存`DX:AX`；除法：被除数存`DX:AX`，商存`AX`，余数存`DX` |
| **标志影响** |       `ADD`/`SUB`/`AND`/`OR`       |     `FLAGS`      |   运算结果会更新`FLAGS`中的状态标志（如`ZF`、`CF`、`SF`）    |
