### TimeStamp类 成员变量 & 成员函数 作用总结

### 一、成员变量

| 成员变量名称            | 类型    | 作用                                                         | 调用 / 存在条件                                              |
| ----------------------- | ------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| microSecondsSinceEpoch_ | int64_t | 存储自纪元（Epoch，通常是 1970 年 1 月 1 日 00:00:00 UTC）以来的微秒数 | 属于 Timestamp 类的私有成员（代码未显式标注访问权限，但为类内变量），只要 Timestamp 对象存在，该变量就存在；对象初始化时被赋值，后续可通过成员函数间接操作 |

### 二、成员函数

#### 1. 构造函数

| 函数签名                                  | 作用                                                         | 调用条件 / 时机                                              |
| ----------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Timestamp()                               | 无参构造函数，将 microSecondsSinceEpoch_初始化为 0，创建一个表示 “纪元起始时刻” 的 Timestamp 对象 | 显式调用`Timestamp()`时（如`Timestamp ts;`），或创建对象未传入参数时 |
| Timestamp(int64_t microSecondsSinceEpoch) | 带参构造函数，接收一个表示 “自纪元以来微秒数” 的 int64_t 类型值，初始化 microSecondsSinceEpoch_，创建指定时刻的 Timestamp 对象 | 显式调用`Timestamp(xxx)`时（如`Timestamp ts(1690000000000000);`），或通过其他函数（如 now ()）隐式调用时 |

#### 2. 静态成员函数

| 函数签名               | 作用                                                         | 调用条件 / 时机                                              |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| static Timestamp now() | 获取当前系统时间对应的 Timestamp 对象：内部调用`time(NULL)`获取自纪元以来的秒数（time_t 类型），并通过带参构造函数创建 Timestamp 对象（注：代码中存在精度损失，秒数直接作为微秒数传入） | 需要获取 “当前时刻” 的 Timestamp 对象时调用，如`Timestamp ts = Timestamp::now();`；main 函数中打印当前时间时也会调用 |

#### 3. 普通成员函数

| 函数签名                     | 作用                                                         | 调用条件 / 时机                                              |
| ---------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| std::string toString() const | 将 Timestamp 对象表示的时间转换为 “YYYY/MM/DD HH:MM:SS” 格式的字符串：1. 把 microSecondsSinceEpoch_（int64_t）强制转换为 time_t 指针，传入`localtime()`获取本地时间的 tm 结构体；2. 通过`snprintf()`将 tm 结构体中的年、月、日、时、分、秒格式化到字符数组；3. 将字符数组转换为 std::string 返回 | 需要将 Timestamp 对象的时间以可读字符串形式展示 / 输出时调用，如`std::cout << ts.toString() << std::endl;`；main 函数中打印当前时间时会调用 now () 返回对象的 toString () 方法 |

### 补充说明

1. 类型转换风险：`localtime(reinterpret_cast<const time_t*>(µSecondsSinceEpoch_))` 依赖 time_t 和 int64_t 的内存表示兼容，若平台上 time_t 不是 64 位整型（如 32 位系统），会导致时间解析错误；且 now () 函数仅传入秒数（time_t）却按微秒数初始化，会丢失微秒精度。
2. 函数依赖：toString () 依赖`<time.h>`的 localtime ()（转换时间戳到本地时间结构体）和`<stdio.h>`的 snprintf ()（格式化字符串），调用 toString () 时需确保这些头文件已包含。
3. 不可变性：toString () 被声明为`const`，调用时不会修改 Timestamp 对象的 microSecondsSinceEpoch_值，可安全用于 const 对象。

### noncopyable 类成员函数总结（按调用条件 & 时机分类）

#### 一、删除的成员函数（禁止调用，无合法调用时机）

| 函数名称                                               | 函数类型       | 调用条件（原本）                                             | 被删除后的作用                                               |
| ------------------------------------------------------ | -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `noncopyable(const noncopyable &other) = delete`       | 拷贝构造函数   | 1. 使用已存在的 noncopyable 对象（或派生类对象）初始化新对象时；2. 函数按值传递 noncopyable 类对象时；3. 函数返回 noncopyable 类对象（值返回）时；4. 容器插入 / 拷贝 noncopyable 类对象时（如 vector 的 push_back 值传递） | 禁止通过拷贝构造的方式创建 noncopyable 类（及派生类）对象，从根源上杜绝对象拷贝行为 |
| `noncopyable &operator=(const noncopyable &) = delete` | 赋值运算符重载 | 1. 已初始化的 noncopyable 对象（或派生类对象）被赋值为另一个同类型对象时（如`obj1 = obj2`）；2. 容器重新赋值 noncopyable 类对象时 | 禁止对 noncopyable 类（及派生类）对象进行赋值操作，避免对象间的赋值拷贝 |

#### 二、受保护的默认成员函数（仅派生类可调用，有明确调用时机）

| 函数名称                   | 函数类型     | 调用条件 & 时机                                              | 作用                                                         |
| -------------------------- | ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `noncopyable() = default`  | 默认构造函数 | 1. 派生类对象被默认构造（无参构造）时，编译器会先调用基类 noncopyable 的默认构造函数；2. 派生类构造函数中未显式调用基类构造时，自动调用该默认构造 | 允许 noncopyable 作为基类时，派生类对象能正常完成构造（保证对象创建的基础流程） |
| `~noncopyable() = default` | 析构函数     | 1. 派生类对象生命周期结束被析构时，先析构派生类自身资源，再调用基类 noncopyable 的析构函数；2. 无手动调用时机（析构函数由编译器自动调用） | 允许 noncopyable 作为基类时，派生类对象能正常完成析构（保证资源释放的基础流程） |

> * `noncopyable` 的设计目标是**作为 “工具基类”，禁止派生类的拷贝 / 赋值**，而非作为 “多态基类” 被指针 / 引用指向派生类对象并删除。
> * 实际使用中，`noncopyable` 仅作为 “混入类”，派生类对象始终以自身类型存在（不会通过 `noncopyable` 指针 / 引用销毁），因此非虚析构完全安全。
> * `noncopyable` 不会被多态使用，虚析构带来的额外开销（虚函数表）是无意义的。非虚析构避免了不必要的性能开销，且不影响派生类正常析构。
> * 人话就是，noncopyable类不会作为指针或者引用接收子类对象，而是子类自身指向自身，析构时【先调用子类析构函数，再调用基类析构函数】

#### 补充说明

1. 成员变量：noncopyable 类无任何成员变量，仅通过控制成员函数的访问权限和默认行为实现 “禁止拷贝赋值、允许正常构造析构” 的核心逻辑；
2. 访问权限设计：默认构造 / 析构设为 protected，既保证派生类能继承使用，又禁止外部直接创建 noncopyable 对象（符合 “仅作为基类使用” 的设计初衷）；
3. 无成员函数实现：所有成员函数均通过`= delete`/`= default`控制行为，无需编写具体实现代码，因为核心目的是约束语法层面的对象操作，而非实现业务逻辑。
