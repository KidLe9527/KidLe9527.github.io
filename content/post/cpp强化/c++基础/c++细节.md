### 一、`goto` 的基本语法

不同语言的语法略有差异，但核心逻辑一致：

1. 定义一个**标签**（Label）：用标识符加冒号（如 `label:`）标记目标位置；
2. 使用 `goto` + 标签名：跳转到该标签处执行

```c
#include <stdio.h>
int main() {
    int i = 0;

loop_start:  // 定义标签
    i++;
    printf("i = %d\n", i);
    if (i < 3) {
        goto loop_start;  // 跳转到loop_start标签
    }

    return 0;
}
```

输出

```c
i = 1
i = 2
i = 3
```

## 常量指针vs指针常量

要区分 **指针常量** 和 **常量指针**，核心秘诀是：**看 `const` 修饰的是谁 —— 修饰指针变量本身，就是指针常量；修饰指针指向的内容，就是常量指针**。

可以用一个简单口诀记忆：**“左定值，右定向”**

- `const` 在 `*` 左边：修饰 “指向的内容”（值不能改）→ 常量指针；
- `const` 在 `*` 右边：修饰 “指针变量本身”（指向不能改）→ 指针常量。

> 常量指针首先是一个常量，才是指针，所以首先其值不能变，然后由于是指针，所以指向的值不能变，但是可以改变指向；
>
> 指针常量，是一个指针，然后是常量，所以是一个指针并且不能改变指向，但是可以修改值;  int * const a = &x; a = &x, 可以修改x的值，因为常量的是a（假设 int x = 10；）

```cpp
#include<iostream>
using namespace std;

int main() {
    int a = 10, b = 20;
    
    // 定义常量指针：指向的内容不能改，指针本身能改
    const int *p = &a;  // p指向a（合法）
    
    // 1. 尝试通过指针修改指向的内容 → 编译报错（const修饰内容，值不能改）
    // *p = 100;  // 错误：assignment of read-only location '*p'
    
    // 2. 指针本身重新指向其他变量 → 合法（指针变量可以改）
    p = &b;  // p现在指向b（没问题）
    cout << *p << endl;  // 输出：20（能正常访问新指向的内容）
    
    return 0;
}
```

```cpp
#include<iostream>
using namespace std;

int main() {
    int a = 10, b = 20;
    
    // 定义指针常量：必须初始化，指向不能改，内容能改
    int *const p = &a;  // 初始化时绑定a的地址（必须这么写）
    
    // 1. 尝试修改指针的指向 → 编译报错（const修饰指针本身，指向不能改）
    // p = &b;  // 错误：assignment of read-only variable 'p'
    
    // 2. 通过指针修改指向的内容 → 合法（内容没被const修饰）
    *p = 100;  // 修改a的值（p还是指向a）
    cout << a << endl;  // 输出：100（a被成功修改）
    
    return 0;
}
```





> //const int& a =10;合法——编译器自动优化   ----》 常量引用才能右值字面量，普通引用不可以初始化幼稚字面量
>
> ```cpp
> int temp = 10;  // 1. 隐式创建一个匿名临时变量temp，赋值为10
> const int& a = temp;  // 2. 让常引用a绑定到temp（a是temp的别名）
> ```
>
> const int * a = 10; //报错， int * 是指针a， a不能接受字面量（指针没有引用的优化）⚠️

* 引用实质上就是指针常量 int* const   a  -------   int & a, 并不是完全等于
