并查集

1. 什么是并查集

​ 并查集（Union-Find），也称为不相交集合（Disjoint Set），是一种用于管理**分组（集合）**的高效数据结构。它主要处理以下两种操作：

  1. 查找（Find）：确定某个元素属于哪个集合（通常返回集合的代表元素）
  2. 合并（Union）：将两个元素所在的集合合并为一个集合

2.并查集的核心思想是：

  • 用树结构表示集合，每个集合用一棵树表示，树的根节点作为该集合的代表元素。

  • 每个元素最初都是一个独立的集合（即自己是自己的代表）

  • 相同集合的元素最终都指向同一个根节点

  • 通过查找元素的根节点，我们可以判断两个元素是否属于同一集合

3. 并查集的两种技术优化

​ 为了提高效率，通常使用两种优化技术：路径压缩和按秩合并

  1. 路径压缩

在Find操作时，将查找路径上的所有节点直接连接到根节点，使树变得更扁平，从而加速后续的查找操作。

  1. 按秩合并

在Union操作时，总是将较小的树合并到较大的树下，或者更准确地说，将秩较小的树合并到秩较大的树下，以控制树的高度，保持树的平衡。

注：这里的"秩"通常是树高度的上界估计，而不是精确的高度

4.并查集的基本操作

  • make_set()：让每一个元素自己成为一个子集合
  • find()：找到集合的代表（根结点）
  • union：合并两个集合

5.代码展示 

#include <vector>

class UnionFind {
private:
    std::vector<int> parent;  // 父节点数组
    std::vector<int> rank;    // 秩数组（用于按秩合并优化）

public:
    // 构造函数，初始化n个元素，每个元素自成一个集合
    UnionFind(int n) {
        parent.resize(n);
        rank.resize(n, 0);  // 初始秩为0
        for (int i = 0; i < n; ++i) {
            parent[i] = i;  // 每个元素的父节点初始化为自己
        }
    }

    // 查找操作：找到元素x的根（代表元素）
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩优化
        }
        return parent[x];
    }

    // 合并操作：将x和y所在的集合合并
    void unionSet(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        if (rootX == rootY) return;  // 已经在同一集合
        
        // 按秩合并：将秩小的树合并到秩大的树下
        if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;  // 秩相同，合并后秩增加
        }
    }

    // 检查x和y是否在同一集合
    bool connected(int x, int y) {
        return find(x) == find(y);
    }
};
